1. ENDEREÇAMENTO DE REDE E PORTAS
--------------------------------------------------------------------------------
Simulador Siemens S7:
  - Protocolo: S7comm (ISO-on-TCP / RFC 1006 / COTP)
  - IP Padrão: 192.168.1.50
  - Porta: 102 (TCP)
  - Rack: 0 | Slot: 1 ou 2
  - Bloco de Dados Simulado: DB1 (100 bytes)

Simulador Rockwell (Allen-Bradley):
  - Protocolo: EtherNet/IP (CIP - Common Industrial Protocol)
  - IP Padrão: 192.168.1.51
  - Porta: 44818 (TCP)
  - Tipo de Acesso: Tag Simbólica (Symbolic Tag Addressing)

3. COMO ADICIONAR NOVAS TAGS NO CÓDIGO
--------------------------------------------------------------------------------
Todas as tags são definidas no arquivo: main.go

-> Para adicionar no SIEMENS (função iniciarS7):
   1. Escolha o próximo byte disponível respeitando o tamanho do tipo:
      - BOOL: bit do byte (ex: byte 0, bit 2: DB1.DBX0.2)
      - INT:  ocupa 2 bytes (ex: offset 24: DB1.DBW24)
      - DINT: ocupa 4 bytes (ex: offset 26: DB1.DBD26)
      - REAL: ocupa 4 bytes (ex: offset 30: DB1.DBD30)
   2. Adicione a linha no main.go:
      srv.SetReal(db, 24, 85.5)        // Define valor inicial
      srv.SetBool(db, 0, 2, true)
   3. Se quiser que o valor varie no tempo, adicione a lógica dentro do
      loop "go func()" usando: srv.SetReal(db, 24, novoValor)

-> Para adicionar no ROCKWELL (função iniciarRockwell):
   1. Registre o nome da tag e o tipo no main.go:
      srv.AddTag("Nivel_Tanque", enipsim.TypeReal)
      srv.AddTag("Valvula_Aberta", enipsim.TypeBool)
      srv.AddTag("Horas_Operacao", enipsim.TypeDInt)
      srv.AddTag("Modo_Controle", enipsim.TypeInt)
   2. Defina o valor inicial:
      srv.SetReal("Nivel_Tanque", 50.0)
      srv.SetBool("Valvula_Aberta", true)
   3. Se quiser simular variação contínua, altere no loop "go func()":
      srv.SetReal("Nivel_Tanque", nivelAtual + 0.5)

4. COMPILAÇÃO E DEPLOY NO ECU-1051 (ARM)
--------------------------------------------------------------------------------
Sempre que fizer alterações no código:

Passo 1 (No Windows - Computador de Desenvolvimento):
  Abra o PowerShell na pasta do projeto e execute:
  .\build-arm.ps1

  O executável será gerado em: dist\simuladores-linux-armv7

Passo 2 (Copiar para o ARM via SCP):
  scp dist\simuladores-linux-armv7 root@192.168.1.50:/home/simuladores/simuladores-linux-armv7

Passo 3 (No ARM):
  Garanta a permissão de execução:
  chmod +x /home/simuladores/simuladores-linux-armv7

--------------------------------------------------------------------------------
5. GERENCIAMENTO DO SERVIÇO E REINICIALIZAÇÃO NO ARM
--------------------------------------------------------------------------------
Como o ECU-1051 usa sistema de arquivo industrial Read-Only e inicialização
pelo arquivo /etc/rc.local:

A) Como reiniciar os simuladores sem reiniciar o aparelho:
   killall simuladores-linux-armv7
   S7_IP=192.168.1.50 ENIP_IP=192.168.1.51 /home/simuladores/simuladores-linux-armv7 > /dev/null 2>&1 &

B) Como reiniciar todo o aparelho:
   reboot

C) Linha de inicialização configurada no /etc/rc.local:
   S7_IP=192.168.1.50 ENIP_IP=192.168.1.51 /home/simuladores/simuladores-linux-armv7 > /dev/null 2>&1 &

D) Se precisar editar o /etc/rc.local no futuro:
   mount -o remount,rw /          # Libera escrita na partição
   vi /etc/rc.local               # Edita o arquivo
   mount -o remount,ro /          # Protege a partição novamente

--------------------------------------------------------------------------------
6. DIAGNÓSTICO E COMANDOS ÚTEIS NO ARM
--------------------------------------------------------------------------------
- Ver se o simulador está rodando:
  ps | grep simuladores

- Ver portas 102 e 44818 abertas:
  netstat -tulpn | grep -E '102|44818'

- Matar processo que esteja travando a porta:
  killall -9 simuladores-linux-armv7
  # ou
  fuser -k 102/tcp
  fuser -k 44818/tcp

- Testar leitura e escrita via rede a partir do Windows:
  go run ./cmd/cliente-teste 192.168.1.50 192.168.1.51
